## ✨ Featured Projects

### 🦖 [**Dinoco**](https://github.com/dinoco-rs/dinoco)  
A modern ORM for **Rust**, inspired by **Prisma**: you describe the schema and Dinoco takes care of the models, typed queries and migrations.  

**Highlights:**  
✅ Schema-driven modeling.  
✅ Typed queries validated at compile time.  
✅ Migrations for PostgreSQL, MySQL and SQLite.  
✅ Its own CLI and a VS Code extension.

### ⚙️ [**Rekka**](https://github.com/dinoco-rs/rekka)  
Job queues and a typed cache for **Rust** on top of **Redis**. Part of the Dinoco ecosystem and safe to scale horizontally.  

**Highlights:**  
✅ Typed jobs with retries, scheduling and per-queue timeouts.  
✅ Recurring workers on an interval or cron, run on exactly one instance per cycle.  
✅ Typed cache with TTL and templated keys.  
✅ Keeps working when Redis goes down and resends jobs once it's back.  

[![Crates.io](https://img.shields.io/crates/v/rekka.svg?color=black)](https://crates.io/crates/rekka)
[![Docs](https://img.shields.io/badge/docs-dinoco.io-black.svg)](https://dinoco.io/docs/rekka)
